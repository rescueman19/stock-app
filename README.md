# 급락주 스크리너 휴대폰 앱 만들기

코스피 상위 100개, 나스닥 100개 종목 중 최고점보다 30% 넘게 떨어진 종목을
매일 자동으로 찾아서 휴대폰 앱으로 보여줍니다.

**컴퓨터를 켜 둘 필요가 없습니다.** GitHub(깃허브)라는 무료 사이트가 매일 대신 계산하고,
휴대폰 앱은 그 결과를 받아서 보여주기만 합니다.

처음 한 번만 컴퓨터로 약 15분 설정하면 됩니다.

---

## 1단계. 깃허브 가입 (컴퓨터에서)

1. https://github.com 접속 → 오른쪽 위 **Sign up** 클릭
2. 이메일, 비밀번호, 아이디를 입력하고 가입을 마칩니다.
   아이디는 나중에 앱 주소에 쓰이니 기억해 두세요.

## 2단계. 앱 보관함 만들기

1. 로그인 후 오른쪽 위 **＋** 버튼 → **New repository** 클릭
2. **Repository name** 칸에 `stock-app` 입력
3. 아래에서 **Public**(공개)을 선택합니다.
   공개여야 휴대폰 앱이 결과를 받아올 수 있습니다. 비밀번호 같은 정보는 들어가지 않습니다.
4. 맨 아래 초록색 **Create repository** 클릭

## 3단계. 파일 올리기

1. 받은 압축파일을 풀고 `stock-app` 폴더를 엽니다.
2. 깃허브 화면 가운데의 **uploading an existing file** 글자를 클릭합니다.
3. 폴더 안에 있는 것 **5개를 모두 선택해서** 깃허브 화면으로 끌어다 놓습니다.
   `.github` · `data` · `mobile_app` · `stock_screener` · `README.md`
   ※ `.github` 폴더가 빠지면 자동 실행이 안 됩니다. 꼭 함께 올려 주세요.
4. 올라가는 표시가 끝나면 아래 초록색 **Commit changes** 클릭

## 4단계. 첫 결과 만들기

1. 위쪽 메뉴에서 **Actions** 클릭
   (초록 버튼으로 사용 동의를 묻는 화면이 나오면 눌러서 허용)
2. 왼쪽 목록에서 **매일 급락주 찾기** 클릭
3. 오른쪽의 **Run workflow** → 초록색 **Run workflow** 클릭
4. 5~10분 뒤 초록색 체크 ✅ 가 뜨면 완료

같은 화면의 **안드로이드 앱 만들기**는 3단계에서 파일을 올릴 때 자동으로 시작됩니다.
이것도 10분쯤 뒤 초록색 체크가 뜨면 앱이 완성된 것입니다.

## 5단계. 휴대폰에 설치 (갤럭시에서)

1. 휴대폰 인터넷 창에 아래 주소를 입력합니다. (`아이디`는 본인 깃허브 아이디)
   `https://github.com/아이디/stock-app/releases`
2. **app-release.apk** 를 눌러 내려받습니다.
3. 다운로드가 끝나면 **열기**를 누릅니다.
4. "출처를 알 수 없는 앱" 안내가 나오면 **설정** → **이 출처 허용**을 켜고 뒤로 가기
5. **설치** 누르기
   - "Play 프로텍트" 경고가 나오면 **세부정보 더보기** → **무시하고 설치**
   - 직접 만든 앱이라 플레이스토어 등록이 안 되어 있어서 나오는 경고입니다.
6. 홈 화면의 **급락주 스크리너** 아이콘을 누르면 끝입니다.

이후로는 매일 자동으로 결과가 바뀌고, 앱에서 화면을 아래로 당기면 새로 불러옵니다.

---

## 자동으로 갱신되는 시간

| 시장 | 갱신 시각(한국 시간) |
|---|---|
| 국내 코스피 | 평일 오후 4시 10분쯤 |
| 미국 나스닥 | 화~토 오전 7시 10분쯤 |

깃허브 사정에 따라 10~30분 늦어질 수 있습니다.

## 추가 설정 (하고 싶을 때만)

깃허브 보관함 → **Settings** → 왼쪽 **Secrets and variables** → **Actions** →
**New repository secret** 에서 아래 이름과 값을 하나씩 등록합니다.

| 이름(Name) | 넣을 값 | 효과 |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | 텔레그램 봇 토큰 | 새 종목이 생기면 텔레그램으로 알림 |
| `TELEGRAM_CHAT_ID` | 텔레그램 채팅 번호 | 〃 |
| `KRX_ID` / `KRX_PW` | 한국거래소 데이터마켓플레이스 계정 | 국내 주가 정확도 향상 |

텔레그램 알림 설정 방법은 `stock_screener/README.md`의 5번 항목에 있습니다.

## 조건 바꾸기

`stock_screener/config.py` 파일의 `default_config` 부분에서 바꿀 수 있습니다.
깃허브 화면에서 파일을 열고 연필 ✏️ 아이콘을 누르면 바로 수정됩니다.
(기본값: 3년 최고점 대비 -30%, 미국은 5거래일 연속 유지)

## 문제가 생기면

- **Actions 화면에 빨간 ❌ 가 뜰 때**: 그 항목을 눌러 빨간 부분을 캡처해서 보여주세요.
- **앱에서 "결과가 없습니다"가 나올 때**: 4단계를 한 번 더 실행해 주세요.
- **앱을 새로 받아 설치할 때**: 기존 앱을 지우지 않고 그대로 덮어써 설치하면 됩니다.

컴퓨터에서 더 자세한 화면(백테스트, 재무 필터 등)을 쓰는 방법은
`stock_screener/README.md`에 있습니다.

※ 이 앱은 매수 후보를 추리는 참고용이며, 투자 판단과 책임은 본인에게 있습니다.
