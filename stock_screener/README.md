# 고점 대비 급락주 스크리너

KOSPI 시가총액 상위 100개, NASDAQ-100 구성 종목 중 최고점 대비 크게 하락한 종목을 찾아
매수 검토 후보군을 만드는 개인용 앱입니다.

## 1. 설치

Python 3.11 이상이 필요합니다.

```bash
cd stock_screener
python -m venv .venv
.venv\Scripts\activate          # 맥·리눅스: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # 맥·리눅스: cp .env.example .env
```

## 2. 실행

```bash
streamlit run app.py            # 윈도우는 run_app.bat 더블클릭도 가능
```

브라우저가 열리면 왼쪽에서 시장과 조건을 고릅니다. 첫 실행은 15년치 시세를 받느라
수 분 걸리며, 이후 같은 날에는 캐시(`cache/`)를 사용합니다.

인터넷 없이 화면만 먼저 보고 싶으면 `.env`에서 `STOCK_DEMO=1`로 바꾸고 실행하면
가상 데이터로 동작합니다.

## 3. 화면 구성

| 탭 | 내용 |
|---|---|
| 스크리닝 결과 | 조건 충족 종목 표, CSV·Excel 내려받기, 이력 저장 |
| 종목 차트 | 종가·20일선·기준 최고점·-30% 기준선·RSI |
| 최고점 기준 비교 | 사상 최고가 / 52주 / N년 기준 결과를 나란히 비교 |
| 백테스트 | 과거 진입 사례의 3·6·12개월 수익률, 지수 대비 초과수익, 승률, MDD |
| 진입·이탈 이력 | 저장된 실행 결과 기준 신규 진입·이탈 기록 |

## 4. 지표 정의

- **하락률**: (현재 종가 − 기준 최고점) ÷ 기준 최고점 × 100, 수정주가 기준
- **사상 최고가**: 수집 기간(`config.py`의 `HISTORY_YEARS`, 기본 15년) 안의 최고 종가
- **지속거래일**: 하락률 조건을 연속으로 충족한 거래일 수
- **지수대비(%p)**: 종목 하락률 − 최고점일 이후 같은 기간 지수 등락률. 음수일수록 시장보다 더 빠진 것
- **20일선돌파**: 최근 3거래일 안에 종가가 20일 이동평균선을 아래에서 위로 넘은 경우
- **RSI반등**: 최근 10거래일 안에 RSI(14)가 30 이하였다가 현재 30을 넘은 경우
- **10일내신저가**: 52주 최저가가 최근 10거래일 안에 나온 경우(아직 하락 중이라는 뜻)
- **거래량배율**: 당일 거래량 ÷ 직전 20일 평균 거래량

## 5. 선택 설정 (`.env`)

**KRX 계정(`KRX_ID`, `KRX_PW`)**: pykrx 1.2 이상은 KRX 데이터마켓플레이스 로그인이 필요합니다.
비워 두면 FinanceDataReader로 자동 대체되지만, 수정주가 정확도를 위해 등록을 권합니다.

**OpenDART(`DART_API_KEY`)**: https://opendart.fss.or.kr 에서 무료 발급. 국내 종목의 영업이익 흑자 여부,
영업이익 증감률, 부채비율 조회에 쓰입니다. 없으면 PER·PBR·ROE만 표시됩니다.

**텔레그램 알림**
1. 텔레그램에서 `@BotFather` → `/newbot` → 발급된 토큰을 `TELEGRAM_BOT_TOKEN`에 입력
2. 만든 봇에게 아무 메시지나 보낸 뒤 `https://api.telegram.org/bot<토큰>/getUpdates` 접속
3. 결과의 `chat` → `id` 값을 `TELEGRAM_CHAT_ID`에 입력

**카카오톡 나에게 보내기**: Kakao Developers에서 앱 생성 → 카카오 로그인 활성화 →
동의항목 '카카오톡 메시지 전송' 설정 → OAuth로 액세스·리프레시 토큰 발급 후 입력.
액세스 토큰은 약 6시간마다 만료되며 리프레시 토큰과 REST API 키가 있으면 자동 갱신합니다.
리프레시 토큰 자체도 약 2개월 후 만료되므로 주기적으로 재발급이 필요합니다.

## 6. 자동 실행과 알림

```bash
python scheduler.py              # 켜두면 국내 평일 16:10, 해외 화~토 07:10(KST)에 실행
python scheduler.py --once ALL   # 한 번만 실행
```

PC를 계속 켜두기 어렵다면 윈도우 '작업 스케줄러'에 `python scheduler.py --once KR`을
원하는 시각으로 등록하는 방식이 더 안정적입니다. 휴장일에는 기준일이 바뀌지 않아 자동으로 건너뜁니다.

자동 실행은 `config.py`의 `default_config()` 조건(국내: 3년 최고가 −30%, 해외: 여기에 5거래일 연속)을
사용합니다. 조건을 바꾸려면 이 함수를 수정하세요. 조건이 바뀌면 이력도 별도로 쌓입니다.

## 8. 한계와 유의사항

- **생존편향**: 백테스트는 현재 구성 종목으로 과거를 검증하므로 결과가 실제보다 좋게 나올 수 있습니다.
- **데이터 소스**: yfinance·pykrx·FinanceDataReader는 비공식 무료 수단으로, 간헐적으로 막히거나 형식이
  바뀔 수 있습니다. 문제가 생기면 `core/sources.py`의 해당 클래스만 수정하면 됩니다.
- **NASDAQ-100 목록**: 위키백과에서 받아오며, 실패 시 코드 안의 예비 목록(2025년 기준)을 씁니다.
- **재무 데이터 기준 차이**: 국내 영업이익은 최근 사업연도 연간, 해외는 최근 4분기 기준입니다.
  해외 부채비율은 총차입금/자기자본이라 국내(총부채/자기자본)와 직접 비교하면 안 됩니다.
- **외부 공개 시**: 본인만 쓰는 경우는 무관하나, 다른 사람에게 배포하거나 유료화할 경우
  자본시장법상 유사투자자문업 신고 대상 여부와 공무원 겸직허가를 사전에 확인해야 합니다.
- 이 앱은 후보를 추리는 도구이며, 투자 판단과 책임은 사용자에게 있습니다.
